## Design tokens

Use these tokens for all colours, as CSS custom properties wired into your Tailwind config. Don't hard-code colours in components. The values are made up for this task.

| Token | Light | Dark | Use |
| :--- | :--- | :--- | :--- |
| `--color-bg` | `#FFFFFF` | `#121418` | Page background |
| `--color-surface` | `#F6F7F9` | `#1B1E24` | Card background |
| `--color-text` | `#1A1D23` | `#EEF0F3` | Main text |
| `--color-muted` | `#5B6270` | `#A3AAB6` | Secondary text, labels |
| `--color-accent` | `#2457D6` | `#7AA2FF` | Progress fill, focus ring, links |
| `--color-track` | `#E3E6EB` | `#2C313A` | Empty part of progress bar, chart grid |
| `--color-success` | `#1E7F4F` | `#4CC38A` | Completed state |
